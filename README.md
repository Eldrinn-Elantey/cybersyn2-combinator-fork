# Cybersyn 2 Constant Combinator Fork

[![FACTORIO](https://img.shields.io/badge/dynamic/json?color=orange&label=Factorio&query=downloads_count&suffix=%20downloads&url=https://mods.factorio.com/api/mods/cybersyn2-combinator-fork)](https://mods.factorio.com/mod/cybersyn2-combinator-fork) [![COMMUNITY](https://img.shields.io/badge/Discord-Community-blue?logo=discord)](https://discord.gg/FcFEu36QBc) [![GitHub](https://img.shields.io/badge/Github-Source-white?logo=github)](https://github.com/Eldrinn-Elantey/cybersyn2-combinator-fork)

Fork of [Cybersyn 2 Constant Combinator](https://mods.factorio.com/mod/cybersyn2-combinator) by moral1ty, based on version 2.1.4. The code comes from [mods_factorio](https://github.com/VladislavPrimakov/mods_factorio/tree/master/cybersyn2-combinator).

## What it does

- Adds a constant combinator for Cybersyn 2 station settings, with a Combinator tab and a Settings tab
- Edits network masks with a 32-bit encoder and lists the network flags in use on your map
- Shows the live request and supply priorities of the signals in your station groups
- Opens and configures combinators placed as ghosts

## Compatibility

The fork uses the same combinator entity (`cybersyn2-constant-combinator`) as the original, so combinators in an existing save keep working after you swap the mods. Because of that, the two mods cannot run together, and Factorio refuses to enable both. Disable the original first.

Requires Factorio 2.1, Cybersyn 2, 0-things and fcore.
